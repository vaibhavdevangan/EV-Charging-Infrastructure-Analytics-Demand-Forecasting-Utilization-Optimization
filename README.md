# EV Charging Demand, Utilization & Infrastructure Analytics


This project analyzes electric vehicle (EV) charging infrastructure data to uncover demand patterns, assess station utilization, and derive actionable insights for optimizing charging networks. Using a synthetic but relationally consistent dataset spanning 2024–2025, the project explores session-level charging behavior, hourly station metrics, and contextual factors such as weather and traffic to support data-driven infrastructure planning and operational decision-making.

## Tools & Technologies

This project will leverage **SQL** for data querying and transformation, **Python** for exploratory analysis and data processing, **Machine Learning** for predictive modeling and forecasting, and **Power BI** for interactive dashboards and visual reporting.
